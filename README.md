# ParkAlto - Sistema de Parqueo

- Wilmer Chura (Integrante A - Líder)
- Wilmer Chura (Integrante B)

## Descripción
ParkAlto es un sitio web para un sistema de parqueo de vehículos en la ciudad de El Alto, Bolivia. Permite conocer los servicios, consultar las tarifas, ver qué espacios están libres u ocupados y reservar un lugar mediante un formulario con validación.

## Tecnologías
- HTML
- CSS
- JavaScript

## Funcionalidades
- Menú de navegación con versión móvil (botón ☰)
- Mostrar/ocultar información adicional de tarifas
- Buscador de espacios por código (ej: A1, B3)
- Filtros de espacios: todos, libres y ocupados
- Formulario de reserva con validación de nombre, placa, tipo de vehículo, fecha y horas
- Cálculo automático del costo según tarifa por hora y tope por día completo
